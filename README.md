# EBay Communication PHP SDK

PHP SDK for eBay Communication APIs, combining REST and GraphQL clients.

## Covered APIs

- **Feedback V1 Beta** — buyer/seller feedback
- **Messaging V1** — buyer-seller messaging
- **Notification V1** — event-driven notifications and subscriptions
- **Negotiation V1** — best offer and price negotiation
- **GraphQL** — communication-related queries

## Specs

OpenAPI specs and GraphQL schema are in `specs/`. Implementation not yet started.
